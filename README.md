# bcm-samsung-opensource
Samsung open source releases for some legacy Broadcom-based devices (mainly Rhea platform) and a few Qualcomm ones too, because why not?

## Devices available:
### BCM21553 (Thunderbird?)
* GT-S6102B - Galaxy Y Duos (torino)
### BCM21654 (Rhea)
* GT-B5330L - Chat (zanin)
* GT-B5330 - Chat (zanin)
* GT-S5301L - Pocket Plus (coriplus)
* GT-S5310L - Pocket Neo (corsica)
* GT-S6010L - Music (ivory)
* GT-S6790L - Fame Lite (nevisvess)
* GT-S6810L - Fame (nevis)
### BCM21664 (Hawaii)
* GT-S6293T - Young Duos TV (royvedtv)
### MSM7225A
* SGH-S730G & SGH-S730M - Discover (amazing)
### MSM8974Pro-AC
* SM-G900F - S5 (klte)

## Meanings of the abbreviations in the names
These describe which version of Android the sources are designed for, as follows:
* GB = Gingerbread (2.3)
* ICS = Ice Cream Sandwich (4.0)
* JB = Jelly Bean (4.1-4.3)
* MM = Marshmallow (6.0)

## Note about the "platform" folders
These appear to be entirely useless for custom ROM development as they're simply generic AOSP trees with no device info filled in. Probably were thrown in there to look good to open source community.

## Can't find your device?
Well, enter your device's model number at [Samsung Mobile Open Source](https://opensource.samsung.com/uploadList?menuItem=mobile&classification1=mobile_phone). If you can't find the sources for your device, create an inquiry at [Inquiry Form](https://opensource.samsung.com/requestInquiry) asking for your device's sources since they are good people and _usually_ answer within a day.  
You can create an issue here if you're too shy to ask them :)
